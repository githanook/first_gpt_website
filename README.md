# 하루 — 오늘의 할 일

기존 React + Vite 프로젝트를 활용한 한국어 할 일 관리 웹사이트입니다.
등록, 삭제, 완료 체크, 전체/진행 중/완료 필터와 모바일 반응형 화면을 제공합니다.

## 실행

```powershell
cd D:\config\my-first-app
npm run dev
```

터미널의 Local 주소(보통 http://localhost:5173)를 브라우저에서 엽니다.
node_modules가 없는 새 환경에서는 먼저 npm install을 실행합니다.
종료하려면 터미널에서 Ctrl+C를 누릅니다.
배포용 파일 생성: npm run build (결과: dist 폴더)
배포용 파일 확인: npm run preview (터미널에 표시된 주소 사용)

## 파일 역할

- src/App.jsx: 화면 구성과 등록·삭제·완료·필터 처리. useState로 데이터를 관리하며, 처음 열 때 localStorage를 읽고 목록을 변경할 때 저장합니다.
- src/App.css: 카드, 입력창, 목록 디자인과 모바일 반응형 스타일.
- src/index.css: 전체 글꼴, 배경색, 기본 여백과 키보드 포커스 스타일.
- index.html: React가 표시되는 HTML 틀. 한국어, 페이지 제목, 설명과 아이콘 설정.
- public/todo.svg: 브라우저 탭의 체크 아이콘.
- src/main.jsx (기존 파일 유지): App을 HTML의 root 요소에 연결하는 진입점.

## 기능 확인

1. 입력 후 추가 버튼 또는 Enter로 등록합니다.
2. 빈 내용이나 공백만 입력하면 안내가 표시되는지 확인합니다.
3. 체크박스를 누르면 취소선, 완료 개수, 진행률이 바뀌는지 확인합니다. 다시 누르면 완료가 취소됩니다.
4. 전체/진행 중/완료 필터를 확인합니다.
5. 새로고침해도 목록과 완료 상태가 유지되는지 확인합니다.
6. 휴지통 버튼으로 삭제한 후 새로고침하여 삭제 상태가 유지되는지 확인합니다.
7. 브라우저 창을 약 375px 너비로 줄이고 긴 내용도 가로 넘침 없이 보이는지 확인합니다.

## 저장 방식

localStorage 키는 haru-todos-v1이며 목록을 JSON으로 저장합니다.
같은 브라우저와 같은 사이트 주소에서 유지되고, 브라우저 데이터를 삭제하면 목록도 삭제됩니다.
개발 서버와 preview 서버는 포트가 달라 데이터를 공유하지 않습니다.
저장이 차단되거나 용량이 부족하면 안내합니다. 불러오기에 실패한 데이터는 초기 화면에서 자동으로 덮어쓰지 않습니다.
